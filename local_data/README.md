# Data folder

In here goes all **small** result data that is needed for further analysis 
and loading in any notebooks etc'. 

This data is generated some where else (locally or on the cluster), and also initially
saved somewhere else and **should be explicitly an manually copied into this folder**.   

This folder **should** be checked in to git and the data here should then be loaded and 
used for analysis (notebooks, plots, etc'.)
